The `app_bootstrap` layer (`router.tsx`, `server.ts`, `start.ts`) is the single entry point that configures React Query defaults, request middleware, SEO, and security headers before any route renders. Routes under `routes/_authenticated/` are gated by the centralized Supabase auth middleware from `integrations/supabase/auth-middleware.ts`, which also exposes client/server Supabase instances via `client.ts` / `client.server.ts`. Feature UI lives in `components/dashboard/` and `components/pos/`, composed from shared shadcn-style primitives in `components/ui/`. Pure domain logic (billing, products, receipts, QR, sales, transfers, etc.) is isolated in `lib/*.ts` and consumed by both components and route handlers, keeping UI composition separate from business rules.
