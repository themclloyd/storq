The root is a single TanStack Start (Vite + Nitro) application whose `vite.config.ts` delegates most plugin setup to `@lovable.dev/vite-tanstack-config`, overriding only the server entry (`src/server.ts`) and pre-bundling heavy route-lazy libraries (`@supabase/supabase-js`, `jspdf`, `recharts`, etc.) plus warming the router/routes/components graph for SSR. The frontend app (`frontend_app`) consumes Supabase client-side and maps its routes/data layer onto the database schema defined in `database_schema` (PostgreSQL migrations, RLS policies, stored procedures). Environment variables are templated through `.env.example`, typed via `tsconfig.json`, and locked by Bun's lockfile with a 24-hour minimum release age policy enforced by `bunfig.toml`. Linting/formatting/test tooling (ESLint, Prettier, Vitest) is configured once at this level and consumed by both children.
