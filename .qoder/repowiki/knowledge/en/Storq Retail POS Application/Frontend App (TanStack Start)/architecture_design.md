The app is split by concern under `src/`: `routes/` declares TanStack Router pages (with `_authenticated/` nested for protected screens), `components/ui/` provides shared shadcn-style primitives consumed everywhere, `components/dashboard/` and `components/pos/` compose feature-specific views, `lib/` holds pure business logic (billing, products, receipts, QR, sales, transfers, etc.) used by both components and route handlers, and `integrations/supabase/` centralizes client/server auth middleware so routes can gate on authentication. The bootstrap layer (`router.tsx`, `server.ts`, `start.ts`) wires React Query defaults, request middleware, and SEO before any route renders.
